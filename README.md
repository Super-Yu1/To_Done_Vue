# To_Done · 前端

> To_Done 是一个**极简的个人待办管理系统**：把要做的事一条条写下来，做完了就勾掉。
> **这个仓库是它的前端工程。** 后端是独立的工程（接口默认在本机 `8081`）；
> **演示模式不需要后端也能完整体验**，拉下来就能看。

一句话说清它解决什么：**让你看清还有哪些事没做，并且愿意一件件划掉。**
所以它不做功能堆砌 —— 每条任务只有标题、描述、优先级、截止时间和几张配图；列表只分「未完成」和「已完成」两段，勾掉就划掉、然后沉下去。

---

## 功能

### 任务清单（首页）

- 一行一件事：勾选圈、标题、优先级（低 / 中 / 高）、截止时间、配图
- 点勾选即完成：**先划掉、再下移**，两段动效；未完成的永远在前
- 新建 / 编辑 / 删除（删除有二次确认，任务进回收站而不是消失）
- **配图**：最多 9 张。选图时在本地先压一道（超过 1920px 或 1MB 才压，**GIF 跳过**），带缩略图预览、**拖动排序**、可逐张删除；上传时有进度条
- 筛选与搜索：按状态、优先级、关键字筛；列表触底自动加载更多

### 回收站

- 软删除的任务都在这里：显示删除时间与「还剩多少天可恢复」（天数取自后端配置，前端不写死）
- 支持单个恢复、彻底删除、清空回收站（清空要手动输入「清空」二次确认）

### 账号

- **注册**：邮箱 + 邮箱验证码 + 密码 + 名字
- **图形验证码一律弹窗式**：不常驻在表单里，只在真正用到它的那一步弹出 —— 发邮箱验证码、登录、后台登录（不为一步无关注输入打断填写；更换邮箱的提交本身不需要它）
- 登录、找回密码（邮箱不存在也提示发送成功，防止探测他人邮箱）
- 登录态是认真的：修改密码 / 更换邮箱后旧会话立即失效，会被请回登录页重新登录

### 个人中心

- 「一行一项」的设置页：左边项名、中间当前值、右边动作；改动一律在弹窗里完成
- 基本资料、更换邮箱、修改密码、**头像上传（1:1 取景框，裁成 512×512）**
- 主题三态：跟随系统 / 浅色 / 深色

### 演示模式

- 地址 `/demo`，**免登录、不连后端**，用的是内置示范数据
- 所有功能都能真的点：新建、编辑、删除、切换完成状态、回收站的恢复 / 彻底删除 / 清空都真的生效（内存态，刷新即还原）
- 用途：给朋友看产品时直接打开，或者自己还没注册时先看看它长什么样

### 后台管理（另一套入口）

- `/admin`：管理员登录、用户列表（筛选分页、冻结 / 解冻、注销、改资料、重置密码）、管理员管理
- 页面已完成，等后端接口就绪后联调（当前仍是骨架态）

## 界面上的几个主张

- **单列**：一行一件事，不用表格、不挤成网格
- **克制**：只留能帮人做决定的信息 —— 优先级只有低 / 中 / 高，而且只有「高」用颜色抢注意力
- **同一套语义色**跑浅色与深色两套主题，切换时有一段缓慢过渡
- **内容区随窗口自适应**，宽屏不会把一行拉成横条
- 全站动效都跟随系统的「减少动效」偏好自动收敛

## 跑起来

需要 Node **22.18+ 或 24.12+**。

```bash
npm install
npm run dev        # 打开 http://localhost:5173
```

- **不启动后端也能玩**：直接访问 `/demo`，功能是全的
- 要看真实数据的话：后端跑在 `http://localhost:8081`，并且前端 dev server **必须用 5173**（它已在后端跨域白名单里）；换端口要在后端加白名单，否则请求会被判 403
- `npm run build` 出生产包（会先跑一遍类型检查）

## 技术栈

Vue 3 + TypeScript + Vite + Element Plus + Pinia + vue-router。
颜色只从 `src/assets/main.css` 的语义变量取（换主题 = 换一组取值）；路由两套守卫，用户与管理员登录态互不干扰。
