## 本文件规则

1. **只记「前端还没接入 / 还没确认」的事**：前端接入并验证没问题之后，**整条删除、不留记录**（长期档案看 `CHANGELOG.md` 与 Git 历史）。
2. **每条带写入时间** `YYYY-MM-DD HH:mm`（Asia/Shanghai），写在标题里。
3. **新增写在最上面**（倒序）；同一次写入的多条共用同一时间，此时按紧急度排。
4. **不分类别，一个事项一条**，标题前缀标：
   - `【待接入】` 后端已就绪、前端还没接；
   - `【已改待验】` 后端刚改完，等前端复验；
   - `【约定】` 前端必须按这个做，否则会踩坑；
   - `【未验证】` 已知边界，暂无需动作。
5. 每条写三样：`要做什么` / `为什么` / `后端现状（含证据）`。
6. 写入与删除由 AI 在每轮收尾时做；前端接入确认后说一句，我就把对应条目删掉。
