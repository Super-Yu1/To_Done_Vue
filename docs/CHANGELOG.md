### 2026-10-29 00:27 · 左侧浮岛里的内容跟着一起收：文字 / 分组标题 / 计数 / 底部三按钮不再瞬跳

① **文字**（`AppSidebar` 的品牌名与导航项）：原来靠 `max-width: none → 0` 收宽，而 `none` 不参与插值（离散属性，走到一半才翻转），两个方向都是宽度瞬跳、只剩透明度在淡入淡出。改成 **grid 轨道的 `minmax(0, 1fr) → minmax(0, 0fr)`**，轨道宽度能一路插到 0，与侧栏 280ms 同拍。
