## 二、项目约定

1. **只做电脑 + 平板（横屏）网页适配，不做手机端**：最窄按 **≈900px** 算，横屏平板常见 1024 / 1080 / 1194 / 1366。`≤900 / ≤760 / ≤640` 只是窄窗口兜底，落在这一档「要滚一段才看到内容」是接受的，不再花力气优化。
2. 唯一例外是 `@container` 那几条（按**容器**宽度降级，与视口无关），照旧保留。
3. 中文沟通，个人独立项目；开工前把不明确处问清楚，倾向接受带理由的推荐选项。
4. `docs/系统设计说明书V8.11.md` 只是参考：与用户要求冲突时**以用户要求为准**，不要把「文档与代码不一致」当成阻塞项或待确认项。
5. 后端实际在 **8081**；联调**必须用 5173**（后端 CORS 白名单只认它，换成 5174 会被判 403，而 curl 不带 Origin 所以看着像通的）。
6. 进站三态：有效票 → 任务页；票过期（登录过期）→ 登录页（带 `redirect`）；没有票 → 演示模式。过期票**只判断、不删除**（`utils/token.ts` 的 `readTokenState` 是唯一依据）；`/admin/**` 是另一套守卫。
7. 演示模式 `/demo` 免登录、不请求后端，数据是内置示范数据；写操作都是内存态真实生效、删除真的进演示回收站、刷新即还原；个人中心的资料 / 邮箱 / 密码只提示不保存。
8. 前台骨架 = **左侧边栏 + 主内容区**（flex 外壳，`--sidebar-width: 272px`，主内容上限 **1720px** 居中）；两栏各自内滚、**整页不滚**、滚动条一律隐藏，只认窗口滚动的地方要一起改（`BackToTop`、路由 `scrollBehavior`）；`≤1024px` 回到文档流。
9. **液态玻璃（2026-10-27 三改：一块画布、三层材质）**：页面没有纯白底 —— `html` 上四团光斑（蓝 0.50 / 紫 0.42 / 粉 0.36 + 中段一层 0.40 白光），底色 #e9eff9 → #e9e8f8 → #f9eef4；光斑够饱和，玻璃才有东西可折射。玻璃只认 `--glass-*` / `--seg-*` 令牌，组件里**不写死白色**。**主内容区不铺底色、不加大外框**：悬浮感由三件事一起给 —— 面板填色 `rgba(255,255,255,0.42)` + `blur(34px) saturate(200%)`、0.6 白描边 + `--glass-sheen` 的上下沿内高光、大而散的冷调落影（`--shadow-panel` / `--shadow-card`，alpha 0.18 / 0.16）。层级靠**面积与厚度**分：面板 26px 圆角、工具栏 / 任务卡 20px。深色面板 `rgba(255,255,255,0.09)` + **0.18 白边**（没有这圈边就糊进背景）。文字三级：标题 #111827 / 描述 #6b7280 / 辅助 #9ca3af，深色为纯白 / 60% 白 / 40% 白。输入控件是**凹井**（墨色 5.5% + 内阴影），别在白玻璃上再叠浅白。控件层（2026-10-28 C 方案）：圆角 12 / 30px 紧凑档 9，按钮**一律不投影**（唯一例外是浮在内容上的回到顶部，用 `--shadow-card`），主按钮用纯色 + 内高光、不做外发光；透明的图标 / 文字按钮悬停统一用 `--control-hover`。
