# 更新日志（CHANGELOG）

## 一、文件规则

1. 修订记录**只保留最近 5 条**；写第 6 条时把最旧那条整条删除，不留归档区、不留「历史记录」小节。
2. 时间精确到分钟，格式 `YYYY-MM-DD HH:mm`（本地时间），**最新写在最上面**。
3. 一条记录 = 一次代码改动（同一轮需求里的多处改动合并成一条），格式固定为**标题 + 一段话**：这段话要写清「改了哪些文件、改了什么与为什么、怎么验证的」。
4. 每次改完代码**立即追加**，不攒批；文档、流程、约定的调整**不进修订记录**，直接改第二部分的项目约定。
5. 本文件是项目的**唯一**记录处：`.ai-memory/` 已废弃、不要再建，也别另开 daily / decisions 之类的新文件。

## 二、项目约定

1. **只做电脑 + 平板（横屏）网页适配，不做手机端**：最窄按 **≈900px** 算，横屏平板常见 1024 / 1080 / 1194 / 1366。`≤900 / ≤760 / ≤640` 只是窄窗口兜底，落在这一档「要滚一段才看到内容」是接受的，不再花力气优化。
2. 唯一例外是 `@container` 那几条（按**容器**宽度降级，与视口无关），照旧保留。
3. 中文沟通，个人独立项目；开工前把不明确处问清楚，倾向接受带理由的推荐选项。
4. `docs/系统设计说明书V8.11.md` 只是参考：与用户要求冲突时**以用户要求为准**，不要把「文档与代码不一致」当成阻塞项或待确认项。
5. 后端实际在 **8081**；联调**必须用 5173**（后端 CORS 白名单只认它，换成 5174 会被判 403，而 curl 不带 Origin 所以看着像通的）。
6. 进站三态：有效票 → 任务页；票过期（登录过期）→ 登录页（带 `redirect`）；没有票 → 演示模式。过期票**只判断、不删除**（`utils/token.ts` 的 `readTokenState` 是唯一依据）；`/admin/**` 是另一套守卫。
7. 演示模式 `/demo` 免登录、不请求后端，数据是内置示范数据；写操作都是内存态真实生效、删除真的进演示回收站、刷新即还原；个人中心的资料 / 邮箱 / 密码只提示不保存。
8. 前台骨架 = **左侧边栏 + 主内容区**（flex 外壳，`--sidebar-width: 272px`，主内容上限 **1720px** 居中）；两栏各自内滚、**整页不滚**、滚动条一律隐藏，只认窗口滚动的地方要一起改（`BackToTop`、路由 `scrollBehavior`）；`≤1024px` 回到文档流。
9. **液态玻璃**：页面没有纯白底（`html` 上是三层弥散渐变），玻璃只用 `--glass-*` 一组令牌，深色主题整套换值，组件里**不要写死白色**。
10. 侧栏导航、筛选页签、编辑弹窗的优先级胶囊都是**独立滑块**：JS 量 `offset*` 得位置再 `transform` 过渡；选中按钮**只改文字色与字重，不要再画底色**，否则和滑块叠成两层。
11. 动作类提示**一律 `el-tooltip`**（白卡 + `pointer-events: none`），不写原生 `title`；只有「长文本兜住全文」可以留原生。样式收窄**只认 `.el-popper.is-dark`** —— 写成 `.el-popper.el-tooltip` 会把日期面板按成「看得见、点不动」。
12. 苹果蓝 `--color-accent` 只给「搜索聚焦环 + 新建任务按钮」；品牌蓝 `--color-brand` 管选中态 / 进度条 / 勾选；玻璃上的输入井用 `--color-field-*`，三者别互相顶替。
13. 品牌资源只有两枚且同源：`public/logo.svg` + `public/logo.png`（200×200）；`favicon.ico` **已删除、不要再生成**。
14. 认证页：`>1240px` 按 4:6、`901–1240` 收到 45:55、`≤900` 折成上下；高度 `≤880` 另有一档短屏（收内边距，保证页脚在首屏）。左栏内容是一个整体、内部一律左对齐；两页共用 `AuthAside`，差别只有 `lead` 一句。
15. **后台不露头**：用户可见界面不放任何后台入口、也不提「管理员」，后台靠直接访问 `/admin/login`。
16. 设置类页面一行一项（项名 / 当前值 / 动作），表单一律进 420–460px 弹窗，页面上不出现常驻输入框；分组用 `.settings-group`。
17. 演示模式的气泡引导只在 `/demo` 首次进入时出现（写 `localStorage`）；「全部划掉」彩蛋用 **`stats` 全量**判定，粒子走共享 `ConfettiLayer`，动画结束整层销毁。
18. 任务行是**玻璃悬浮卡**（20px 圆角、前置位 40px、标题 16px/600、右侧元信息固定 236px、操作列 60px 悬停显现且只在 `@media (hover: hover)` 下收起）；`@container (max-width: 720px)` 时元信息换到正文下方。回收站行没有前置位。

20. 配图字段：缩略图**兼「点击看大图」与「拖动排序抓取区」**，靠 4px 位移阈值区分；`<img draggable="false">`、删除按钮 `click.stop`、预览用 `ElImageViewer` + `teleported`，这三条少一条就坏。角标只有右上角一个红色 ×（用 `el-tooltip`），最多 9 张。
21. 配图压缩：**长边 >3840 或体积 >3MB** 才 canvas 重绘（质量 0.95、输出 JPEG、透明图先铺白底）；单张 >10MB 在选择时即拦；**只收 JPG/PNG/WebP，GIF 直接拒**（任务配图与头像同口径）。
22. 优先级只有低 / 中 / 高三档（无「紧急」）：任务卡用 `.task-row__prio` 一组，弹窗与批量操作用 `.prio`；口径都是高浅红 / 中浅橙 / 低浅灰。
